<h1 align="center">Novel Director</h1>

<p align="center">和 AI 一起写长篇小说的桌面客户端</p>

<p align="center">简体中文 · <a href="./README.en.md">English</a></p>

一个对话就是一部小说。AI 每轮写一章，章末给出 2 到 3 个走向；你可以选一个、组合几个、补充细节，或者自己写，故事就沿着你的回复往下走。

写到几十万字时，普通聊天很容易忘记设定、写丢伏笔、算错数字。Novel Director 让一个后台模型替你记账，写作模型只管写。

## 特点

**不用手工维护设定。** 人物（性格、说话方式、当前状态）、名词、伏笔和前情由后台自动整理，你不用事先写世界书，也不用边写边补。

**只记定下来的。** 一章要等你再回复两轮左右才入账。你否掉、没接或改动过的走向不会被记下，故事里没发生的事不会混进设定。

**数值记得准。** 钱、等级、战力这类数字按增减逐章累计。刚写下的变化立刻算进下一章的上下文；正文和账对不上的地方会标出来，由你选按账还是按正文，不会被悄悄改掉。

**世界保持自洽。** 一个可选的世界观模型会推敲物价、等级和战力的关系，推出来的值标为"推定"，并写明依据。

**账本归你管。** 每一条都能直接改或删，删了还能恢复，你动过的内容后台不会再改回去。

**长篇也稳。** 上下文按预算组装，老伏笔会带着原文被召回；章节目录可以折叠，点一下就跳到那一章。

**写作体验。** 对白按主题配色，与叙述分开；开写之前和章与章之间，可以先和叙述者聊设定、聊走向，这些交流也会被记下。

## 模型

写作、后台和世界观三个角色各自选模型，常见搭配是：一个文笔好的模型写正文，一个便宜的模型记账。不设后台模型时，它就是一个普通的 AI 对话客户端。

支持 DeepSeek、Claude、OpenAI、Gemini、通义千问、Moonshot、智谱、火山引擎、硅基流动、OpenRouter、Ollama、LM Studio 等，也可以添加任何兼容 OpenAI 接口的服务。API key 由你自己填写。

## 数据

小说、设定和 API key 都只保存在你的电脑上。没有账号，没有统计，没有错误上报；除了你自己配置的模型服务和你打开的联网搜索，它不连接任何服务器。

## 运行

目前没有预编译的安装包，需要从源码运行。需要 Node.js 22 和 pnpm 10。

```bash
pnpm install
pnpm start
```

打包安装程序（Windows、macOS、Linux）：

```bash
pnpm package
```
